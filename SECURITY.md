---

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

Please do NOT create a public GitHub issue for security vulnerabilities.

Instead, contact:

- Email: support@ryanplugins.net
- Website: https://ryanplugins.net

Please include:

- Detailed description of the issue
- Steps to reproduce
- Affected plugin version
- Any proof-of-concept or screenshots

We will investigate all legitimate reports and respond as quickly as possible.

---

## Security Best Practices

To keep your WooCommerce store secure:

- Always use the latest plugin version
- Keep WordPress, WooCommerce, and PHP updated
- Use SSL/HTTPS on checkout pages
- Use strong administrator passwords
- Limit admin access permissions
- Regularly backup your website

---

## Disclosure Policy

We appreciate responsible disclosure and will work with security researchers to verify and resolve reported vulnerabilities promptly.

Thank you for helping improve the security of our plugins and the WordPress ecosystem.
